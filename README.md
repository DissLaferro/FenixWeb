# Сайт сервера Fenix

## Структура проекта

```
fenix-website/
├── index.html      # Главная страница
├── styles.css      # Стили
├── script.js       # JavaScript
├── images/         # Папка для изображений
│   ├── logo.png          # Логотип сервера (рекомендуемый размер: 512x512px)
│   ├── server-main.png   # Главное изображение для секции "О сервере" (рекомендуемый размер: 800x500px)
│   ├── gallery-1.png     # Большой скриншот для галереи (рекомендуемый размер: 800x500px)
│   ├── gallery-2.png     # Скриншот (рекомендуемый размер: 400x250px)
│   ├── gallery-3.png     # Скриншот (рекомендуемый размер: 400x250px)
│   ├── gallery-4.png     # Скриншот (рекомендуемый размер: 400x250px)
│   ├── gallery-5.png     # Высокий скриншот (рекомендуемый размер: 400x500px)
│   └── gallery-6.png     # Скриншот (рекомендуемый размер: 400x250px)
└── README.md       # Этот файл
```

## Что нужно добавить

### Обязательные изображения:

1. **logo.png** — Логотип сервера Fenix
   - Размер: 512x512px (квадрат)
   - Формат: PNG с прозрачностью
   - Стиль: Греческая тематика, оранжево-золотые цвета на тёмном фоне

2. **server-main.png** — Главное изображение в секции "О сервере"
   - Размер: 800x500px или 16:10
   - Что показать: Красивый вид спавна или ключевой локации сервера

### Галерея (6 скриншотов):

1. **gallery-1.png** (БОЛЬШОЙ, занимает 2x2 ячейки)
   - Размер: 800x500px
   - Рекомендация: Эпичный вид спавна или храма

2. **gallery-2.png** (обычный, 1x1)
   - Размер: 400x250px
   - Рекомендация: Босс-битва или данж

3. **gallery-3.png** (обычный, 1x1)
   - Размер: 400x250px
   - Рекомендация: Уникальные предметы/артефакты

4. **gallery-4.png** (обычный, 1x1)
   - Размер: 400x250px
   - Рекомендация: Постройки игроков

5. **gallery-5.png** (ВЫСОКИЙ, 1x2 ячейки)
   - Размер: 400x500px
   - Рекомендация: Высокое здание, статуя бога и т.д.

6. **gallery-6.png** (обычный, 1x1)
   - Размер: 400x250px
   - Рекомендация: Ивент или группа игроков

## Как добавить изображения

1. Помести все изображения в папку `images/`
2. Открой `index.html` в текстовом редакторе
3. Найди нужный placeholder и замени его на `<img>` тег

### Пример замены:

**Было (placeholder):**
```html
<div class="gallery-placeholder">
    <svg viewBox="0 0 24 24" fill="currentColor">
        <path d="M21 3H3C2 3 1 4 1 5V19C1 20 2 21 3 21H21C22 21 23 20 23 19V5C23 4 22 3 21 3ZM5 17L8.5 12.5L11 15.51L14.5 11L19 17H5Z"/>
    </svg>
    <span>images/gallery-1.png</span>
</div>
```

**Стало (с изображением):**
```html
<img src="images/gallery-1.png" alt="Описание изображения" class="gallery-img">
```

## Запуск сайта

Просто открой `index.html` в браузере. Сайт статичный, сервер не требуется.

Для разработки можно использовать Live Server в VS Code или любой локальный сервер.
